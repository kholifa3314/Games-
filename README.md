# Flappy Guy (Standalone Game Folder)

Everything needed to run the game is inside this single `flappy-guy-game` folder (`index.html`, `style.css`, `game.js`, `character-asset.js`, and `character.jpg`). No software installation or build tools are required.

## How to Run on Your Own

### Option 1: Double-Click (No Software Needed)
1. Keep all files in the same `flappy-guy-game` folder.
2. Double-click `index.html` to open it directly in any web browser (Chrome, Edge, Safari, Firefox).

### Option 2: Run with a Local Web Server (Optional)
Open a terminal inside the `flappy-guy-game` folder and run:
- Python: `python3 -m http.server 8080` then open `http://localhost:8080`
- Node.js: `npx serve .`

### Option 3: Host Online for Free
Upload the `flappy-guy-game` folder directly to **GitHub Pages**, **Netlify Drop**, **Cloudflare Pages**, or **Vercel** to play it from any phone or computer.

## Controls
- **PC**: Press **Space** or **Click** to fly upward (`Esc` or `P` pauses)
- **Mobile**: **Tap** anywhere on the screen to fly upward
